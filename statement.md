# Problem Statement

Student management in educational institutions often involves handling student records, marks, and performance tracking manually. This process can be time-consuming, error-prone, and difficult to maintain when the number of students increases. The Student Management System is a command-line Java application designed to simplify these tasks by providing a structured way to store and manage student information efficiently.

The project addresses the need for a simple and reliable system to add new students, update their details, search for particular records, delete student entries when necessary, and maintain academic marks. It also supports basic performance evaluation by calculating total marks, percentage, and grade, which helps instructors and administrators monitor student progress more effectively.

# Scope of the Project

The scope of this project includes creating and managing student records through a command-line interface using Core Java. The system stores student data in a simple file-based format so that information can be retained between sessions. It supports essential operations such as adding, viewing, searching, updating, and deleting student records.

The project also covers academic record management, including adding marks, calculating total marks, percentage, and grade, and generating a basic performance report for an individual student. Input validation and error handling are included to reduce invalid data entry and improve the reliability of the application.

# Target Users

The primary users of this project are students, teachers, and administrative staff who need a simple way to manage student information and academic performance. It is especially useful in a small academic environment where records are maintained manually and a lightweight digital solution is required.

This system is suitable for users who need an easy-to-use command-line application without complex setup or heavy infrastructure. It is designed to support basic academic administration with clear and direct interaction.

# High-Level Features

- Add student records with required personal information
- View all stored student details
- Search for a student by ID
- Update existing student information
- Delete student records
- Add marks for students
- Calculate total marks for a student
- Calculate percentage based on marks
- Calculate grade based on academic performance
- Generate a student performance report
- Validate user input to reduce errors
- Store student data using basic file-based storage
- Handle invalid operations and input errors effectively

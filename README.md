# Student Management System

## 1. Project Overview

Student Management System is a command-line based Java application developed to manage student information and academic records.

The system allows users to add, view, search, update, and delete student records. It also provides marks management and student performance report generation.

The project is designed using Core Java concepts such as Object-Oriented Programming, ArrayList, File Handling, Input Validation, and Exception Handling.

---

## 2. Objectives

The main objectives of this project are:

- To manage student information efficiently.
- To perform CRUD operations on student records.
- To manage and calculate student marks.
- To calculate total marks, percentage, and grade.
- To generate student performance reports.
- To validate user input and handle invalid data.
- To provide a simple command-line interface.

---

## 3. Features

### Student Management

- Add a new student
- View all students
- Search student by ID
- Update student information
- Delete student information

### Marks Management

- Enter marks for different subjects
- Validate marks between 0 and 100
- Calculate total marks
- Calculate percentage
- Calculate grade

### Report Management

- Generate student performance report
- Display student details
- Display total marks
- Display percentage
- Display grade
- Display pass/fail status

### Validation

- Validate student ID
- Validate student name
- Validate age
- Validate email
- Validate marks
